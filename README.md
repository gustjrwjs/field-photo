# 현장사진

현장조사용 사진 기록 앱 (PWA). 링크: https://gustjrwjs.github.io/field-photo/

- 촬영하면 GPS 좌표·시각이 자동으로 붙고, 번호·지점명·분류·메모를 입력
- 사진에 정보 글자(스탬프)를 넣어 내보내기 — 항목·위치는 설정에서 선택
- **조사표**: 지점(구간)별 조사 항목 입력. 기본 양식은 하도육역화 현장조사표
  (하도형태, 초본류·교목류·관목류, 분포 형태, 밀생정도, 수고, 흉고직경, 수관폭)
- **내보내기**: ZIP(지점별 폴더 사진 + 조사표.csv + 사진목록.csv + 위치.kml), 사진 공유
  내보낸 JPG에는 촬영일시·GPS가 EXIF로 들어가 QGIS·구글어스에서 위치가 잡힘
- 사진은 폰 브라우저 안(IndexedDB)에만 저장. 서버 전송 없음 → 조사 끝나면 ZIP으로 백업

## 보고서 만들기 (PC 브라우저)
- 폰: 내보내기 → ZIP 저장 → PC로 옮김
- PC: 앱 링크의 '보고서(PC)' 탭에 ZIP을 끌어다 놓으면 채워진 한글 파일(.hwpx)이 다운로드됨 (`hwpx.js`가 브라우저 안에서 양식을 채움)
- 양식: `tpl/myeong.hwpx`, `tpl/je.hwpx` (원본 .hwp를 한글에서 HWPX로 저장한 것). 다른 양식은 .hwpx를 ZIP과 같이 넣으면 됨
- 구간 표마다 빈 칸을 채움: 식생 8칸 + 사진 2장 + 사진 설명 2칸 (하도형태 등 이미 적힌 칸은 그대로)

## 파일
- `index.html` 화면, `app.js` 기능, `sw.js` 오프라인 캐시, `manifest.webmanifest`·아이콘: 홈 화면 설치용
- `start.bat`: PC에서 미리보기 (http://localhost:8766)
- `hwpx.js`: 한글 HWPX 채우기
- `publish.ps1`: 공개 저장소(gustjrwjs/field-photo)에 올려 링크 갱신. 평소에는 `sync.ps1`이 자동 실행
- 이 폴더의 `.hwp`·`.dwg`(조사표 원본)는 공개 저장소에 올라가지 않음
